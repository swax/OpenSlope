Before you drop in

A few trail notes.

What Slopesmith does, what you need, and where it fits.

Is this an SSX Tricky map editor?

Yes. Slopesmith authors SSX Tricky-compatible courses and exports portable maps. OpenSlope’s Snowknife tools handle importing from a user-supplied PS2 disc image and repacking authored maps into the game. You can also build entirely original courses and ride them in Slopesmith.

Do I need a copy of the game?

For original courses and browser riding, no. You need Node.js 24 and the OpenSlope repository to run the editor locally. Importing retail courses or repacking for the original game requires a user-supplied disc image that you are permitted to make and use.

Can I play the original SSX Tricky here?

Slopesmith’s browser riding is an independent implementation, with its own riders and features. It does not include the original characters or trick system. To ride a compatible exported course with the original game’s rules, use the repacking workflow and your own copy of the game.

Does it work on mobile and in VR?

A running Slopesmith server can be accessed from desktop and mobile browsers, with touch and gamepad controls for riding. Standalone Quest headsets use WebXR without PC streaming. Remote and VR access require the appropriate HTTPS server setup.

Can I edit with other people?

Yes. Host a private server to invite members, edit shared mountains, and see other riders live. Accounts, roles, per-mountain permissions, project history, and optional self-hosted voice chat are part of the server workflow.
