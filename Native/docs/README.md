# Native implementation documentation

This directory documents Native's behavior, import mappings, application
approximations, build and release procedures, and validation results.

Original-game research, executable addresses and symbols, detailed
derivations, and local capture/input paths belong in the local Trailmap
research workspace. Component documentation uses clean behavioral/format
conclusions and cites their `[Trailmap: anchor]` identifiers. The optional
research workspace is not required by a fresh OpenSlope checkout.

Follow the repository's [research boundary](../../CONTRIBUTING.md#reverse-engineering-hygiene)
and keep implementation provenance accurate. Publication checks enforce this
document boundary; they do not establish legal clearance or clean-room origin.
