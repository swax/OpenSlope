# OpenSlope Native 0.89.0

Adds preliminary Jonny Moseley Mad Trix USA PS2 import through the shared native
loader. Windows, Quest and Slopesmith can load eleven courses from a user-supplied
BIN or ISO, with curved terrain, textures, source sky domes, baked colored terrain
lighting and adapted starts.

Narrow source grind strips become approximate rails. Supported neon and marquee
props retain source art with adapted animation; Las Vegas also includes its two
animated waterfalls. Source riding sounds take priority, with missing roles able
to use locally extracted SSX Tricky sounds. All twelve Mad Trix music tracks are
available through the shared playlist player, with whole-track looping.

Original collision flags, scripts, triggers, music scheduling and some props
remain deferred. See [Mad Trix import and limits](../docs/madtrix-import.md).

Older Mad Trix maps need re-importing to receive the new assets and metadata.
Existing native map folders are preserved; extract into a fresh folder when
keeping local edits. Quest app updates retain maps and settings.
