# OpenSlope Native 0.80.0

- Original SSX courses can load riding sprites from their nested `Textures/Particles` folder. Sprite paths still reject traversal and absolute paths.
- On Tour's `-1` unscored paths no longer become zero-distance race lines or false finish locations. Valid zero-distance lines remain supported, and original `.tp` records are preserved.
- Finish locations tolerate float32 endpoint rounding, so valid On Tour routes retain their race finish.
- Uniquely paired On Tour event terrain uses the enabled surface for rendering, collision, image loading and fallback spawn. Source records and patch indices are retained. Unpaired or ambiguous terrain stays available.

Existing SSX imports and paired On Tour terrain work after updating, including Quest Maps-folder caches. Re-import On Tour courses converted by older builds to refresh their race paths; existing course folders are preserved by the importer.

Install the Quest update over the existing app to preserve maps and settings.
SSX 3 and On Tour still have the script, animation, collision and audio limits
documented in their import guides. No retail content is included in the builds.
