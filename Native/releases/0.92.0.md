# OpenSlope Native 0.92.0

This release prepares Windows, Linux x64, macOS Apple Silicon and Intel, and Quest
packages from the same source revision. Desktop packages include the player,
import tools and notices.

macOS graphics fixes negotiate MoltenVK portability extensions, handle Intel
Metal heap compatibility and provide valid buffers for empty scenes. The build
checks also probe Metal resource support to help diagnose driver differences.

SSX 3, its July 2003 preview and On Tour imports recover additional model clips
with their timing and hierarchy. Per-object collision states let tree canopies
pass through while preserving trunk collision proxies. Untranslated challenge
beacons remain hidden while riding.

The shared application version is 0.92.0; Quest uses version code 95 so it can
update an existing installation signed with the same key. Existing maps remain
in place. Re-import into a fresh Maps folder to receive updated effect and
collision metadata without overwriting edited maps. See
[import caching](../docs/import-cache.md) and
[release packaging](../docs/releases.md).
