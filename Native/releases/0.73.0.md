# OpenSlope Native 0.73.0 — bank touchdown preview

Author, convert and ride portable OpenSlope courses on Windows or standalone Quest.

- Fixes a rider sliding against terrain while stuck in the air state.
- Restores ground steering and carve sound after affected bank/tilted-deck landings.
- Retains floor containment when leaving a steep bank at a narrow corner.

Desktop and Quest share the correction. Existing maps need no re-import, and
opponents remain off by default. See `Native/docs/bank-touchdown-0.73.md` for
validation and scope; complete gameplay parity remains unfinished.

Use **Play OpenSlope.cmd** in the Windows package. Add custom courses under
`Maps/NAME`, or use **Import courses.cmd** with a supported user-supplied ISO.
The sideloaded Quest APK can import a local ISO or select an existing Maps folder.
Keep the same signing channel for in-place updates.

No disc images, extracted courses, commercial music or other retail media are included.
GitHub builds remain on demand; see `Native/docs/releases.md` for packaging.
