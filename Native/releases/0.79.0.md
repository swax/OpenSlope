# OpenSlope Native 0.79.0 — desktop and Quest preview

- Improved terrain contact, landings and crash-bag collision.
- Desktop: A/D strafe on foot, left-drag look/turn, E spawn/mount/dismount, including in mid-air.
- Desktop: select ISOs beside the EXE, queue course extractions, then click Play. Lists now scroll.
- Opponents stay off by default; their menu entry is hidden for now.
- Shorter window title and setup instructions.

## Windows

Extract the Windows ZIP and open **OpenSlope.exe**. Put your SSX Tricky PS2 ISO beside
the EXE, choose **ISO Sources**, then **Extract** a course. The button becomes **Play**
when ready. Custom maps go in `Maps/NAME`. Press **Escape** for controls and settings.
Requires Windows 10/11 x64 and a Vulkan graphics driver.

## Quest

Sideload the Quest APK, then open **OpenSlope** from your app library / **Unknown Sources**.
Choose **Add courses** to import a local ISO or select an existing Maps folder.
You can copy the ISO to the headset's Download folder; extraction happens in the app.
**Trigger** mounts/dismounts, **A** jumps, **B** boosts, **Y** opens the wrist menu.

## Updating

Windows: move your Maps folder beside the new EXE. Quest: install over the previous
release to keep maps and settings. Earlier debug builds use a different signing key;
back up their maps before uninstalling. Do not uninstall to resolve an update error.

This preview has incomplete gameplay parity. Quest 3 has prior device testing;
this build still needs a headset playtest. SSX 3 import is not supported.
No game content is bundled. Licenses ship with each app; download hashes are in
`SHA256SUMS.txt`. Report bugs with version, course and platform at
[GitHub Issues](https://github.com/swax/OpenSlope/issues).
