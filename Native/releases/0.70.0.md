# OpenSlope Native 0.70.0 — forward reset preview

Author, convert and ride portable OpenSlope courses on Windows or standalone Quest.

- Race resets advance by 0.8 seconds of an adjacent competitor's speed.
- The local player and opponents share the forward-bias rule.
- Solo play, Freeride, Showoff, Megaplex and the final 100 metres have no forward bias.
- Custom courses with multiple laps retain the ordinary race rule.

Desktop and Quest use the same implementation. Existing maps need no re-import.
See `Native/docs/reset-bias-0.70.md` for validation, specification interpretation
and remaining terrain/racing parity work.

Use **Play OpenSlope.cmd** in the Windows package. Add custom courses under
`Maps/NAME`, or use **Import courses.cmd** with a supported user-supplied ISO.
The sideloaded Quest APK can import a local ISO or select an existing Maps folder.
Keep the same signing channel for in-place updates.

No disc images, extracted courses, commercial music or other retail media are included.
GitHub builds remain on demand; see `Native/docs/releases.md` for packaging.
