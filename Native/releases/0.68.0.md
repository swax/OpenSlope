# OpenSlope Native 0.68.0 — opponent recovery preview

Author, convert and ride portable OpenSlope courses on Windows or standalone Quest.
This experimental preview improves the optional opponent field on both platforms.

- Keeps recovery anchored to the opponent's tracked route when another line is nearby.
- Applies authored jump/reset windows and respects no-reset sections.
- Resumes the route actually selected for recovery and clears stale route state after teleports.
- Starts slope recovery with the intended horizontal drop-in velocity.

Existing maps need no re-import. Enable opponents in the desktop or wrist menu;
the default remains zero. Full gameplay parity and wider device validation remain
in progress; see `Native/docs/opponent-recovery-0.68.md` for evidence and limits.

Use **Play OpenSlope.cmd** in the Windows package. Custom courses belong under
`Maps/NAME`; **Import courses.cmd** can import from a supported user-supplied ISO.
The sideloaded Quest APK opens its map library and can import a local ISO.
Keep the same signing channel for in-place updates and preserve your maps before
switching channels. Uninstalling can remove app-owned data.

No disc images, extracted courses, commercial music or other retail media are included.
GitHub builds remain on demand; see `Native/docs/releases.md` for release packaging.
