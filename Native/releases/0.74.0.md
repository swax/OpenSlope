# OpenSlope Native 0.74.0 — desktop contact fixes

- Extends bank touchdowns to upward incoming travel, restoring ground controls and carve sound.
- Moves flip rotation to the rider's pelvis, with the board, feet and collision pose following together.
- Clears lingering live crash-bag overlaps while preserving the normal shove impulse.

Desktop and Quest share these changes. Existing maps need no re-import and
opponents remain off by default. See `Native/docs/playtest-contact-0.74.md` for
validation and limits; complete gameplay parity remains unfinished.

Use **Play OpenSlope.cmd** in the Windows package. Custom courses go under
`Maps/NAME`; **Import courses.cmd** accepts a supported user-supplied ISO.
Quest can import a local ISO or select an existing Maps folder. Keep the same
signing channel for in-place updates.

No disc images, extracted courses or commercial media are included. GitHub
builds remain on demand; see `Native/docs/releases.md` for packaging.
