# OpenSlope Native 0.78.0

- Put supported SSX Tricky PS2 ISOs beside the Windows EXE and select them in the app.
- Queue multiple course extractions into Maps, with progress and cancellation in each row.
- Completed rows become Play buttons; extraction does not start a map automatically.
- Scroll course/source/map lists with the wheel or scrollbar instead of paging.
- Play existing/custom maps without an ISO; existing map files and local edits are preserved.
- Start in the library when no explicit course is selected, and refresh newly added sources/maps.
- Retain the 0.76 desktop controls: A/D strafe on foot, left-drag look/turn, E spawn/mount/dismount.

Native SSX 3 import is not implemented. Quest keeps its existing picker flow.
No game content is included. Imported content stays local to your computer.
