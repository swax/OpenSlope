# OpenSlope Native 0.72.0 — curved terrain preview

Author, convert and ride portable OpenSlope courses on Windows or standalone Quest.

- Swept terrain collision follows curved patches more closely.
- Sphere overlaps use the nearest triangle feature consistently.
- Partly embedded bags and other compound props clear the terrain consistently
  and retain their incoming shove.
- Shared rider and prop-body collision use the corrected geometry, with bounded
  subdivision caching and earlier contact pruning.

Existing maps need no re-import. See `Native/docs/curved-terrain-0.72.md` for
validation, approximation limits and remaining full-course parity work.

Use **Play OpenSlope.cmd** in the Windows package. Add custom courses under
`Maps/NAME`, or use **Import courses.cmd** with a supported user-supplied ISO.
The sideloaded Quest APK can import a local ISO or select an existing Maps folder.
Keep the same signing channel for in-place updates.

No disc images, extracted courses, commercial music or other retail media are included.
GitHub builds remain on demand; see `Native/docs/releases.md` for packaging.
