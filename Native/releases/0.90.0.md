# OpenSlope Native 0.90.0

Adds preliminary SSX Tricky GBA import for AXYE revision 0, with eight named
courses, textured terrain and scenery, collision, grind paths, sky assets,
riding sounds and music. Choose a local `.gba` in the Windows or Quest picker;
GBA and PS2 sources remain separate. Source event scripts and original audio
scheduling remain deferred. See [GBA support and limits](../docs/ssx-gba-import.md).

Windows and Quest libraries group maps by game and display source course names.
SSX 3 initially shows named runs, with an advanced toggle for other map types.
New Tricky imports use `TRICKY_` folder IDs; existing folders are not renamed.
See [course names and compatibility](../docs/course-titles.md).

Imports reuse disc readers and verified converted music between courses while
keeping installed maps self-contained. Removing a conversion cache does not
remove a map's music. See [import caching](../docs/import-cache.md).

New 1080° Avalanche imports include 46 named music streams, source-coloured
terrain shadows and separate scenery/rider lighting. Music uses the shared
song picker and whole-track looping; original scheduling remains deferred.
See [Avalanche support and limits](../docs/avalanche-import.md).

Adds portable Ogg Opus music playback for compressed reference exports while
retaining support for existing WAV music and graph identifiers. Source
sidecars and gameplay sound banks remain unchanged.

Existing maps remain in place. Re-import into a fresh folder to receive new
imported assets and metadata while preserving local edits. Quest updates use
the existing release signing identity and retain maps and settings.
