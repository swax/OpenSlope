# OpenSlope Native 0.86.0

- Race and Showoff no longer hold the board for a start countdown. Mounting starts movement, scoring and the event clock together on the first riding tick; waiting on foot still keeps the event ready.
- Restart uses the same immediate start, and AI opponents wait for the local rider's first mount before starting with them.

Includes the equipment-frame fixes, SSX gems and Y-button visibility changes. Quest app updates retain maps and settings; no map re-import is needed.
