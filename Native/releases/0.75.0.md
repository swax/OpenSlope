# OpenSlope Native 0.75.0 — embedded contact correction

- Restores ground controls when the deck is sunk into terrain while its guard touches the surface from above.
- Corrects a Snowdream air-state lock reproduced from a paused desktop playtest.
- Retains takeoff grace, departing-wall checks and soft-snow contact behavior.

Desktop and Quest share the correction. Existing courses need no re-import and
opponents remain off by default. See `Native/docs/embedded-contact-0.75.md` for
validation and scope. Complete gameplay parity remains unfinished.

Use **Play OpenSlope.cmd** in the Windows package. Custom courses go under
`Maps/NAME`; **Import courses.cmd** accepts a supported user-supplied ISO.
Quest can import a local ISO or select an existing Maps folder. Keep the same
signing channel for in-place updates.

No disc images, extracted courses or commercial media are included. GitHub
builds remain on demand; see `Native/docs/releases.md` for packaging.
