# OpenSlope Native 0.85.0

- Mounted board presentation now rebuilds perpendicular axes when heading and carried tilt align, including cancelled interpolation on steep terrain. The previous global-up fallback could align both axes and fail a tracked-hand query with `Invalid equipment frame`.
- Regressions cover aligned and nearly aligned mounted axes through flips and banking. Equipment-frame errors also report axis lengths and alignment to distinguish any remaining failure.

Includes the lost-board slope recovery fix from 0.84, SSX gem import and Y-button visibility changes. Quest app updates retain maps and settings; these equipment fixes do not require re-importing courses.
