# OpenSlope Native 0.83.0

- Original SSX imports retain rigid model animation curves and translate compact animation setup and x2/x3/x5 pickup commands. Showoff gems spin, award their tier, disappear after collection and return on restart.
- Gem models and placements receive labels derived from their pickup effects. Source names, model/instance indices, geometry and raw source records are retained. Decorative copies without a pickup effect keep their ordinary mode presence.
- Slopesmith's bundled importer uses the same conversion and requests a reload of older SSX caches.

Re-import older native SSX course folders to receive the new model/effect metadata. Existing folders are preserved; use a new destination when keeping local edits. Quest app updates retain maps and settings. The Y-button visibility change from 0.82 and 600 metre terrain range from 0.81 remain included.
