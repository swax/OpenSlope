# OpenSlope Native 0.88.0

Adds Enhanced and Runtime lighting on desktop, with HDR, bloom, ray-traced light
shadows and soft rider shadows.

Brings seven selectable avatars to Windows and Quest, with separate desktop
camera-look and avatar-turn controls, improved walking camera behavior, and
fixes for player height and Quest steering.

Improves Quest rendering performance by removing unused lighting and material
work from terrain, props, boards and avatars. The same material optimizations
cover desktop Original, Enhanced and Runtime lighting, including ray shadows.
Desktop benchmark results vary by GPU and lighting mode; a frame-rate gain is
not guaranteed.

XR diagnostic logs now report riding state and scene workload alongside frame
timings. Existing courses work without re-importing. Quest app updates retain
maps and settings.
