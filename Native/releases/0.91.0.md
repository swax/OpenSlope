# OpenSlope Native 0.91.0

PC and Quest now include the recent shared-importer updates for SSX 3, its July
2003 preview, and On Tour: beta discovery, riding audio, original shared fog
sprites, constant UV animation bindings, animated multiplier/collectible
pickups and hidden course helpers. Original conditional scripts and unsupported
material effects remain deferred.

SSX 3/beta, On Tour, 1080 Avalanche and Mad Trix imports assign each map a stable
share of the game-wide soundtrack before conversion. On Tour day/night versions
share songs. Tricky retains its original per-course playlists. Native playback
loads the selected song and its next graph chunk rather than decoding every
song on map load. See [music assignment](../docs/music-assignment.md).

The native renderer reads SSX 3/beta/On Tour per-placement vertex colours through
a bounded shared GPU table, including bright modulation and coverage. Models
remain shared between placements. Rider/board lighting ignores scenery averages
and samples the floor's shade when an explicit actor rig is unavailable. Beta
map selectors use the same named-run and advanced-section filters as retail.
Common fog-volume files now draw through the existing billboard renderer using
the shared authored tint, opacity and puff sizes, and remain present after reset.

Existing maps and edits remain in place. Re-import into a fresh Maps folder to
receive smaller playlists, new fog assets and translated animation/pickup
metadata; do not overwrite an edited map. Existing per-vertex light data is
used directly without reimporting. See [import caching](../docs/import-cache.md).

Local preview packages use the development signing identity. No disc content is
packaged. Headset installation and in-headset performance require device testing.
