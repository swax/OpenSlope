# OpenSlope Native 0.81.0

- Desktop and Quest terrain now use a 600 metre camera range together with frustum culling. Patches intersecting that range stay visible; sky geometry keeps its existing far clip.
- Distance fog fades from 300 to 600 metres, with the course's existing fog colour. Authored fog ending sooner is preserved. This draw policy does not change collision, gameplay, source maps or import caches.
- Dense views no longer fall back to submitting out-of-range terrain. The desktop `--no-terrain-culling` comparison disables frustum selection while retaining the distance gate and matching fog.
- Quest timing logs include the course, terrain patch/index/draw counts and last-eye culling time.

Install over the existing Quest app to preserve maps and settings. Existing courses work without re-importing. Terrain LOD, streaming and occlusion culling remain future work.
