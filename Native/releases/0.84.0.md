# OpenSlope Native 0.84.0

- Lost loose boards now re-align their forward axis when recovering onto a slope. Previously recovery changed only the up axis, so the next tracked-hand query could fail with `Invalid equipment frame`.
- A regression recreates the exact error by losing a board below a sloped course, then checks recovered-board queries and the next tracked-input tick.

Includes the SSX gem import and Y-button visibility changes from 0.83. Quest app updates retain maps and settings; this fix does not require re-importing courses.
