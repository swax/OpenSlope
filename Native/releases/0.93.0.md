# OpenSlope Native 0.93.0

This release includes Windows x64, Linux x64, macOS Apple Silicon and Intel,
and Quest packages from the same source revision. Desktop archives include
the player, import tools and third-party notices.

The July 2003 SSX 3 preview can import courses whose optional fog placements
reference unavailable models. Importers retain the source records and report
warnings while preserving the recoverable fog. Malformed records still fail
validation. This allows the preview's Ruthless course to finish importing.

On Tour imports now use each object's solid-response flag. Tree canopies can
be passed through while trunks keep their collision. Original render meshes,
proxy slots and source geometry remain available; unknown states and ambiguous
layouts retain their previous behavior.

On Tour halo and beam draws preserve explicit glow materials in the common
map data, including separate variants when ordinary surfaces share the same
source material. Slopesmith plays these materials with additive blending;
Native rendering still approximates their appearance rather than reproducing
the original light shaders.

The shared version is 0.93.0; Quest uses version code 96 and the existing
release signing identity. Existing maps remain in place. Re-import into a
fresh Maps folder to receive the updated fog, collision and material data
without overwriting edited courses. See
[import caching](https://github.com/swax/OpenSlope/blob/native-v0.93.0/Native/docs/import-cache.md)
and [release packaging](https://github.com/swax/OpenSlope/blob/native-v0.93.0/Native/docs/releases.md).
