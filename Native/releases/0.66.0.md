# OpenSlope Native 0.66.0 — desktop and Quest preview

Author, convert and ride portable OpenSlope courses on Windows or standalone Quest.
This is an experimental release; gameplay parity is still in progress.

- Up to sixteen optional opponents use the same terrain, board physics and course interactions as the player.
- Desktop and wrist menus offer opponent controls and standings. Courses without AI paths remain playable solo.
- Includes stick figure avatars, board carrying/throwing, on-foot flight, course effects, audio and graphics settings.
- Recent fixes improve steep jump-corner collision, flare appearance and desktop UI rendering with supersampling.

## Windows

Download the Windows x64 ZIP and extract it into a writable folder. Open **Play OpenSlope.cmd**.
The procedural slope works immediately. Add custom maps to `Maps/NAME`, or use **Import courses.cmd**
to convert a local supported SSX Tricky PS2 ISO. Restart the player after importing, then select **Maps**.
See **START HERE.txt** for controls and PC VR. Windows 10/11 x64 and a Vulkan graphics driver are required.

## Quest

Download the Quest ARM64 APK. With developer mode and USB debugging enabled, install through a
trusted APK sideloading tool or `adb install -r <downloaded-apk>`. Open **OpenSlope** from your
app library (sideloaded apps may appear under **Unknown Sources**). The initial library lets you select
existing custom maps or import a local ISO. You can transfer your ISO to a user-visible headset folder
such as Download; the app imports selected courses into its Maps folder. No PC extraction is required.

Right A jumps, B boosts, either trigger mounts/dismounts, grips carry/throw, X recalls equipment,
and Y opens the wrist menu. The menu includes graphics, audio, opponents and exit. Performance varies
by course, resolution and opponent count. Quest 3 has device validation; other declared Quest devices
still need testing. The default 120 fps target is a request, not a guaranteed measured frame rate.

## Updates and verification

Quest updates require the same signing certificate and an equal or newer Android version code.
A release-signed APK cannot update an earlier debug-signed test install. Back up maps with ADB
before deliberately changing signing channels; uninstalling
can remove app-owned maps and preferences. Do not uninstall just to resolve an update error.

`SHA256SUMS.txt` records each download's checksum. `release-manifest.json` records the source commit,
APK signing certificate and package contents. Application/dependency notices ship in the Windows ZIP
and inside the APK. No disc images, extracted courses, commercial music or other retail media are bundled.

Known limits include incomplete full-course opponent racing, multiplayer, wider device coverage and
remaining gameplay/audio/rendering parity. Report issues at [GitHub](https://github.com/swax/OpenSlope/issues)
with the version, course and reproduction steps; do not attach private game assets.
