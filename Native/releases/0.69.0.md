# OpenSlope Native 0.69.0 — landing and terrain corners preview

Author, convert and ride portable OpenSlope courses on Windows or standalone Quest.
This experimental preview improves shared terrain contact during landings.

- Checks the new collision frame immediately after landing near another surface.
- Stops cached probes from pulling airborne riders back onto walls they have left.
- Retains clearance from multiple terrain surfaces at narrow corners.
- Uses a verified clear starting centre when edge constraints would demand a distant correction.
- Preserves soft-snow depth and ordinary impact controls without an automatic stuck reset.

Desktop and Quest use the same corrected physics. Existing maps need no re-import.
See `Native/docs/landing-frame-0.69.md` for validation and remaining parity work.
Rising platforms and rail exits retain their support transitions. Wider route,
collision and multiplayer behavior remain part of the unfinished parity work.

Use **Play OpenSlope.cmd** in the Windows package. Add custom courses under
`Maps/NAME`, or use **Import courses.cmd** with a supported user-supplied ISO.
The sideloaded Quest APK can import a local ISO or select an existing Maps folder.
Keep the same signing channel for in-place updates; uninstalling can remove
app-owned maps and settings.

No disc images, extracted courses, commercial music or other retail media are included.
GitHub builds remain on demand; see `Native/docs/releases.md` for packaging.
