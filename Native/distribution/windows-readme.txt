OpenSlope Native - Windows

1. Extract the ZIP into a writable folder and open OpenSlope.exe.
2. Put your SSX Tricky PS2 ISO beside the EXE. Open ISO Sources and click
   Extract for each course you want. When ready, the button becomes Play.
   Custom maps go in Maps/NAME and work without an ISO.
3. Use the mouse wheel to browse. Refresh finds newly added files.

WASD move/steer, E mount/dismount, Space jump, Shift boost, left-drag look.
Press Escape for the menu, full controls, graphics and audio settings.
For PC VR, set your active OpenXR runtime and open Play in VR.cmd.

Requires Windows 10/11 x64 and a Vulkan graphics driver. SSX 3 import is not
supported. No game content is included. Licenses are in licenses/.

To update, extract the new release and move your Maps folder beside its EXE.
Report bugs with version and course: https://github.com/swax/OpenSlope/issues
